An Efficient Malware Detection Approach Based on Machine Learning Feature Influence Techniques for Resource-Constrained Devices

Welcome to Our AI-Powered Malware Detection

Our project leverages advanced machine learning techniques to detect malware efficiently, optimized for resource-constrained devices. Below are the key details of our approach:

Algorithms

  • Random Forest Classifier: Utilizes ensemble learning to combine multiple decision trees for robust malware detection.
  • Extra Trees Classifier: An extension of Random Forest with additional randomization for enhanced accuracy and efficiency.
  • Decision Tree: A simple yet effective model that creates a tree-like structure to make decisions based on feature splits.
  • XGBoost: An advanced gradient boosting algorithm that optimizes performance through parallel processing and regularization.

Our proposed methods aim to enhance detection accuracy while maintaining efficiency, making them suitable for deployment on resource-constrained devices.
